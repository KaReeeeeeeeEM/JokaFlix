# How to Collaborate

We welcome collaboration from anyone who wants to improve JokaFlix.

## Ways You Can Help

- Report bugs or broken features
- Suggest new features or improvements
- Improve UI/UX design
- Fix issues in the codebase
- Improve documentation
- Test the app on different devices
- Share feedback about performance or usability

## Before You Start

1. Check existing issues to avoid duplicating work.
2. If your idea is large, open an issue first so we can discuss it.
3. Fork the repository and create a new branch for your work.
