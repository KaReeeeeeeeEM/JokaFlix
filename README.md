# JokaFlix

JokaFlix is a movie and series streaming experience focused on discovery, watchlists, ratings, recommendations, user profiles, and admin analytics.

## How to Collaborate

Direct pushes to this repository are not allowed. All contributions must be made through a pull request.

## Steps to Contribute

1. Fork this repository.

2. Clone your fork.

   ```bash
   git clone https://github.com/YOUR_USERNAME/JokaFlix.git
   cd JokaFlix/jokaflix
   ```

3. Create a new branch.

   ```bash
   git checkout -b feature/your-feature-name
   ```

4. Install dependencies.

   ```bash
   pnpm install
   ```

5. Run the project locally.

   ```bash
   pnpm dev
   ```

6. Make your changes.

7. Commit your changes.

   ```bash
   git add .
   git commit -m "Describe your change clearly"
   ```

8. Push your branch to your fork.

   ```bash
   git push origin feature/your-feature-name
   ```

9. Open a pull request from your fork to this repository.

## Pull Request Guidelines

Before opening a pull request:

- Make sure your branch is up to date with the main branch.
- Keep your changes focused on one feature, fix, or improvement.
- Explain clearly what you changed and why.
- Add screenshots if your change affects the UI.
- Test your changes locally before submitting.
- Do not include unrelated files or personal environment files.

## Collaboration Rules

- Do not push directly to the main repository.
- Always work from your own fork.
- Use a separate branch for each feature or fix.
- Discuss large changes in an issue before working on them.
- Be respectful when reviewing or receiving feedback.
- Pull requests may be reviewed, requested for changes, approved, or closed.

## Branch Name Examples

```bash
feature/add-watch-later
fix/login-redirect-loop
ui/improve-profile-page
docs/update-readme
```
